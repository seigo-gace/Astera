# Asteraの追加Option

Asteraでは、通常の判断材料生成に必要な処理だけを追加できます。

Optionは、実行前に利用者が選択する追加処理です。Settingsの表示ToggleをONにしただけでは実行もCredit消費も始まりません。実行前の確認画面で、選択内容と予定Creditを確認してから開始します。

> 現在、このページは確定しているOption仕様を公開するものです。外部Providerや保存先を含む本番提供は準備中です。利用開始時期は[現在の公開状態](current-status.md)で案内します。

---

## 現在の4つのOption

| Option | 何をするか | 主な対象 | Creditの考え方 |
|---|---|---|---|
| 高精度翻訳 | 本文の構造を保ったまま、指定言語へ翻訳する | Basic以上 | 入力換算量の50%を追加 |
| エージェントモード | 複数Stepで調査・確認・処理を進める | 利用可能Planは公開Catalogに表示 | Modeと実行内容に応じ、開始前に見積り |
| 書類作成 | 公式または個別Templateへ内容を反映する | Pro以上を基本範囲とする | Templateと処理内容に応じ、開始前に見積り |
| 外部Storage転送 | 完成した結果を利用者管理のStorageへ一方向転送する | Basic以上 | 入力換算量の50%を追加 |

料金・Plan・Creditの詳細は[Plan・料金・Credit](plans-and-credits.md)をご覧ください。

---

## 高精度翻訳

高精度翻訳は、文章を要約したり書き換えたりする機能ではありません。**本文の内容と構造を維持し、翻訳だけを行う**Optionです。

保持するもの：

- 見出しと段落
- 箇条書きと表
- CodeとURL
- 数字とPlaceholder
- 情報の順番と情報量

行わないもの：

- 要約・解説
- 内容の改善・校正
- Tone変更
- 対象読者向けの再構成
- 追記・削除

翻訳先言語は必須、翻訳元言語と用語集は必要に応じて指定します。

### 向いている場面

- 契約資料や仕様書の構造を崩さず翻訳したい
- 表やCodeを含む文書をそのまま別言語へ移したい
- 翻訳者の補足説明を混ぜず、本文だけを受け取りたい

## エージェントモード

エージェントモードは、単発処理ではなく複数Stepで作業を進めるOptionです。利用者はLow・Medium・Highから選びます。

| Mode | 最大Step | 主な使い方 | 外部変更の扱い |
|---|---:|---|---|
| Low | 3 | 短い確認や読取中心の作業 | 読取専用 |
| Medium | 8 | 調査や複数項目の確認 | 外部へ書き込む前に承認 |
| High | 15 | 複数Toolを使う複雑な作業 | 危険性のある操作ごとに承認 |

初期提供では、送信、削除、購入、Credential変更などを利用者の承認なしに自動実行しません。Step上限、再試行、Credit上限、停止条件を超えた場合は途中成果を完成扱いせず停止します。

### 向いている場面

- 複数の情報源を順番に確認したい
- 調査→比較→確認までを一つの作業として進めたい
- 外部操作を行う前に必ず確認を挟みたい

## 書類作成

書類作成は、Asteraで整理した内容を、公式Templateまたは利用者が登録した個別Templateへ反映するOptionです。

### 固定書式の書類

Googleスプレッドシートでは、原本を利用者のDriveへ複製し、許可されたCellまたはNamed Rangeだけを変更する設計です。

次の要素は勝手に変えません。

- 数式
- 罫線、行高、列幅
- 結合Cellと保護範囲
- Chart
- 印刷設定

許可範囲外の変更やLayout崩れが見つかった場合は、完成または自動転送として扱いません。

### 文章文書

Googleドキュメントは文章文書用として扱います。固定書式を完全に維持するSpreadsheetとは、保証範囲を分けます。

### 向いている場面

- 決まった書式の報告書や管理表を作りたい
- 毎回同じTemplateへ内容だけを反映したい
- 数式やLayoutを壊さず指定欄だけを更新したい

---

## 外部Storage転送

外部Storage転送は、Asteraから利用者が管理するStorageへ、完成した結果を一方向にCopyするOptionです。

転送後、Asteraは転送先のFileを継続同期・編集・削除しません。

利用者は次を選びます。

- 接続先Account
- 保存先Folder
- File名
- 転送する結果

同じFileが重複して作成されないように確認し、転送結果と最終File名を表示する設計です。

### 向いている場面

- 完成した結果を自分のStorageへ保存したい
- Astera Storageを使わず、既存の管理先へ集約したい
- Private Modeの結果を端末Downloadではなく自分のStorageへ移したい

---

## Optionではない独立機能

次は実行時に追加するOptionではありません。

| 機能 | 位置付け |
|---|---|
| Private Mode | 本文や結果を通常の履歴・Storageへ残さず処理する独立Mode。Basic以上、追加Creditなし |
| 暗号化・鍵管理 | Private ModeやCredentialを保護するSecurity基盤 |
| Astera Storage | 結果やFileを保存する契約容量。Planごとに選択上限が異なる |
| Developer Mode | API Key、利用量、Credit、停止状態を管理するPro以上の開発者向け画面 |

これらをOption一覧へ混ぜないことで、「実行ごとに選ぶ処理」と「Account全体の機能」を区別します。

---

## 選び方

- 原文を崩さず別言語にしたい → **高精度翻訳**
- 複数Stepで調査や処理を進めたい → **エージェントモード**
- 決まった書式の成果物を作りたい → **書類作成**
- 完成結果を自分のStorageへ送りたい → **外部Storage転送**
- 内容を通常保存したくない → **Private Mode**
- Applicationや業務Systemから利用したい → **Developer Mode**

---

## 実行前に確認すること

1. 今回の目的に必要なOptionだけを選ぶ
2. 翻訳先、Agent Mode、Template、転送先などの必須項目を指定する
3. Private Modeや保存先を確認する
4. 予定Creditを確認する
5. 利用者が実行を確定する

Optionを複数選ぶほど予定Creditは増えます。正確な見積りは実行前に表示し、残高不足の場合は処理を開始しません。
