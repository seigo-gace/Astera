# Asteraのはじめかた

Asteraは、難しい設定を覚えなくても使えます。

ここでは、初めて使う人向けに、最も基本的な流れを説明します。

## 1. 整理したい内容を用意する

Asteraへ入れられるのは、質問だけではありません。

- 迷っていること
- 比較したい商品やサービス
- 作成中の計画
- 読んでほしい資料
- AIが作った回答
- 問題が起きたときの状況
- 誰かへ説明したい考え

文章が完璧である必要はありません。

ただし、分かる範囲で次を入れると、判断材料がより具体的になります。

- 何を決めたいのか
- いつまでに必要か
- 予算や時間の上限
- すでに分かっていること
- 絶対に避けたいこと

## 2. 目的を選ぶ

Astera Appでは、内容に合わせて目的を選べます。

| 目的 | 使う場面 |
|---|---|
| レビュー | 資料や計画の見落としを確認したい |
| 比較 | 複数の案を同じ条件で比べたい |
| 検証 | 説明や結論が本当に成り立つか確認したい |
| 改善 | 現在の内容をより良くしたい |
| 調査 | 調べるべき論点を整理したい |
| 計画 | 実行順、条件、依存関係を整理したい |
| 検討 | まだ決めきれない問題を広く考えたい |
| 判断 | 最終的な選択肢と条件を整理したい |
| 原因 | 問題が起きた理由を切り分けたい |

目的を迷う場合は、内容をそのまま入力して構いません。

## 3. 8つの判断材料を読む

Asteraは、入力を次の順で整理します。

1. 本当の目的
2. 前提不足
3. 事実確認
4. 危機察知
5. 反対視点
6. 比較案
7. 推奨判断
8. 主役AIへの再指示

最初から全部を同じ重さで読む必要はありません。

まずは次の3点を見ると、全体をつかみやすくなります。

- **前提不足**：決める前に何を確認する必要があるか
- **危機察知**：どこで失敗しやすいか
- **推奨判断**：現時点では何が妥当か

## 4. 自分で決めるか、主役AIへ渡す

Asteraの結果は、そのまま自分の判断材料として使えます。

より詳しい説明、文章、計画、手順が必要な場合は、「主役AIへの再指示」をChatGPT、Claude、Geminiなどへ渡します。

```text
Astera
判断に必要な骨組みを作る

主役AI
骨組みを使って、説明・文章・計画・回答へ仕上げる
```

## 入力例

```text
現在使っている予約システムを変更するか迷っています。
月額費用は下げたいですが、スタッフ5人が使うため、操作が難しくなるのは避けたいです。
候補はA、B、Cの3つです。
料金、操作性、移行の手間、トラブル時の対応を比べてください。
```

この入力では、単に最安のサービスを選ぶのではなく、移行負担、スタッフ教育、障害時の対応まで含めて比較できます。
