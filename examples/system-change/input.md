# 入力例｜予約Systemを変更するか

現在使っている予約Systemを変更するか迷っています。

現在のSystemは月額5万円で、スタッフ5人が毎日使っています。先月、予約時間の入力ミスが3件ありました。ただし、Systemの不具合なのか、操作ミスなのか、運用手順の問題なのかはまだ確認できていません。

候補はA社とB社です。

- A社：月額3万円。初期費用20万円。操作が簡単だと営業担当から説明されています。
- B社：月額4万円。初期費用5万円。現在のDataを自動移行できると書かれています。

2か月以内に判断したいです。費用は下げたいですが、移行中に予約を失ったり、Staffが操作できなくなったりすることは避けたいです。

全面移行、試験導入、現在のSystemを改善して続ける案を比較し、開始条件と停止条件も整理してください。
