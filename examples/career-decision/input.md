# 入力例｜今すぐ退職して独立するか

現在の仕事を辞めて、個人で仕事を始めるか迷っています。

状況は次のとおりです。

- 現在の手取りは月28万円です。
- 毎月の生活費は約20万円です。
- 貯金は180万円あります。
- 副業収入は直近3か月で、月4万円、7万円、6万円でした。
- 継続契約の顧客はまだいません。
- 現在の仕事は体力的に負担があります。
- 家族は、生活が安定するなら独立へ反対していません。
- 半年以内には方向を決めたいです。

今すぐ退職する、副業を続けながら準備する、転職して負担を減らしてから独立準備をする案を比較してください。開始条件と、独立を延期する条件も整理してください。
