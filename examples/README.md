# 公開サンプル

このDirectoryでは、Asteraが入力をどのように8つの判断材料へ整理するかを、短い例で紹介します。

## サンプル一覧

### 新しいサービスを公開するか判断する

「来月までに新サービスを公開したい」という相談を、目的、前提、危険、比較案へ分けます。

- [入力を見る](service-launch/input.md)
- [8つの判断材料を見る](service-launch/output.md)

## サンプルの読み方

1. まず入力文を読む
2. 自分なら何を確認するか考える
3. Asteraが整理した8項目を読む
4. 特に「前提不足」「危機察知」「比較案」の違いを見る

Asteraの価値は、結論の文章量ではなく、**結論を出す前に見落としていた判断材料が見えること**にあります。

## 表示について

公開サンプルは、初めて見る人にも理解しやすいように短く整えています。

実際の利用では、入力内容や目的に応じて、確認項目や比較条件が変わります。
